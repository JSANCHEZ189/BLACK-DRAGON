# Portafolio Profesional Multimedia — Juan Diego Sánchez

Portafolio web interactivo de alto rendimiento desarrollado con **React**, **TypeScript**, **Vite** y **Tailwind CSS**.

---

## ⚡ 3 Formas de Abrirlo Sin Errores ni Pantalla Blanca

### Opción 1: Doble clic directo (Sin instalar nada)
1. Descarga el ZIP y descomprímelo.
2. Abre directamente el archivo **`portafolio.html`** con doble clic en tu navegador preferido (Chrome, Edge, Firefox, Brave).
3. ¡Listo! Abre de forma instantánea con todas las fotos, videos y estilos ya precompilados.

---

### Opción 2: Ejecutar en tu PC como desarrollador (Recomendado)
Requiere [Node.js](https://nodejs.org/) instalado.
1. Abre la carpeta del portafolio en tu terminal o en Visual Studio Code.
2. Instala las librerías una sola vez:
   ```bash
   npm install
   ```
3. Ejecuta el servidor (puedes usar cualquiera de los dos comandos):
   ```bash
   npm start
   ```
   o también:
   ```bash
   npm run dev
   ```
4. Abre en tu navegador `http://localhost:3000`.

---

### Opción 3: Publicarlo en GitHub Pages (Automático)
El repositorio ya cuenta con el flujo automatizado `.github/workflows/deploy.yml`.
1. Sube tu código a tu repositorio de GitHub.
2. En GitHub, ve a la pestaña **Settings** > en el menú izquierdo haz clic en **Pages**.
3. En **Build and deployment > Source**, selecciona **GitHub Actions**.
4. GitHub compilará y publicará tu web automáticamente en tu enlace gratuito `https://tu-usuario.github.io/tu-repo/`.

---

## 🌐 Publicarlo en Vercel o Netlify (Gratis en 1 minuto)
1. Inicia sesión en [Vercel](https://vercel.com) con tu cuenta de GitHub.
2. Importa este repositorio.
3. Vercel detecta automáticamente Vite. Haz clic en **Deploy**.
4. Tu sitio web quedará disponible 24/7 en un enlace seguro HTTPS.
